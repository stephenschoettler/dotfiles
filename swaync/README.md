# SwayNotificationCenter

Dracula themed SwayNC notification center for Hyprland.

## Layout

- Right-side panel below Waybar.
- High-contrast notification cards with urgency color bars.
- Quick actions: Clear, Hide, Audio, Shot.
- Widgets: DND, MPRIS, volume, backlight, notifications.

## Live reload

```bash
swaync-client -R
swaync-client -rs
```
